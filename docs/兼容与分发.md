# 兼容性与免费分发

2026-10-22，来源按当日刷新；以下区分本机实测、官方范围和待验证项。

## 程序兼容与硬件兼容

CEC 调节的是电视音量，与前台程序的品牌无关。普通浏览器、视频和音乐 App 只要声音输出到该电视，通常无需各自安装插件；这属于架构推断，不是逐个 App 的全量实测。

硬件依赖 Mac 的 CEC 通道、HDMI 连接路径和电视的 CEC 实现。Apple 的[HDMI说明](https://support.apple.com/en-us/108928)列出了支持的 Mac 与转接路径，其中 M4/M4 Pro Mac mini 原生 HDMI 有官方支持。不能把这点推广到所有历代 Mac mini；其他 Apple 芯片机型和转接器需按具体配置及运行时检测核对。Intel 路径未实现。

| 配置 | 当前证据 |
| --- | --- |
| M4 Mac mini、macOS27.0.1、雷鸟65S585C Pro | 家庭版已被用户实测接受，显示报告4K/120Hz，键盘/CEC通过 |
| 通用预览代码在上述硬件上的连接检测 | 本轮单独构建并只读检查，结果见dist验证摘要；不等于新UI已被用户验收 |
| macOS14/15/26 | 编译目标覆盖14起；尚无这些系统上的运行证据 |
| M4 Pro/其他 Apple 芯片 Mac、其他电视 | 需具体型号与连接验证 |
| Intel Mac、多外接屏幕、网络遥控、DDC/软件音量 | 不属于首版实现范围 |

第一版只支持单个外接屏幕，避免把音量发给错误设备。电视屏幕音量变化与光纤音响实际响度不同，不能将前者写成后者已验收。付费流媒体/DRM、音频App独占输出和开机/锁屏期间的行为未做专项验证。

## 已有工具与本项目取舍

- [BetterDisplay功能表](https://github.com/waydabber/BetterDisplay/wiki/List-of-free-and-Pro-features)已提供免费 HDMI-CEC 控制（也有硬件前提）。这是成熟的综合显示管理替代方案，本轮未安装实测。
- [MacTV](https://github.com/pengchujin/MacTV)已有免费开源的原生 CEC 遥控和音量键桥接。本项目参考其MIT实现，保留版权与许可声明；不能声称发明了该通道。
- [MonitorControl讨论](https://github.com/MonitorControl/MonitorControl/discussions/1829)体现电视与普通DDC显示器路径的区别，不能拿旧版“Mac不支持CEC”的说法覆盖当前M4实测。

用户仍选择做自己的免费小工具。首版保持音量任务集中，提供中英文、连接检测、正常菜单/权限入口与安装材料；不为了已有综合工具的功能表扩大为显示管理套件。

## GitHub 预览分发

- 当前候选是实验预览，ad-hoc 签名，未完成 Apple 公证；其他电脑可能被 Gatekeeper 拦截。可从源码构建，不提供关闭系统安全保护的指引。
- 发布包包含源码、预览 DMG、SHA256 和去敏验证摘要。本地诊断与具体连接状态不上传。
- 正式直接下载版可走 Developer ID、Hardened Runtime、时间戳与公证；这不等于 Mac App Store 审核或所有机型功能通过。当前未完成这些发行检查。
- 使用了非公开 IOKit 接口，不把现实现直接作为 Mac App Store 上架候选；参见 [App Review 2.5.1](https://developer.apple.com/app-store/review/guidelines/#software-requirements)。

## 下一步有价值的验证

先收集少量不同硬件的自愿兼容反馈：Mac/系统、电视/接收器、直连还是转接、连接检测、按键与实际音量、声音输出切换。没有新硬件时不重复测同一台来宣称覆盖增长。

分享其他工具可以沿用同样的独立仓库、简单构建、许可证、下载说明与兼容反馈格式；当前不新增可执行第三方插件加载器。
