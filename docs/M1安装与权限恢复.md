# M1 安装验收与辅助功能恢复

2026-10-23，v0.2.0-preview.1 / build 3。Apple M1 Mac mini / macOS 27.0.1 / 一条经用户授权的 Android TV 连接。

## 已确认

- 官方发行已 Developer ID 签名、公证通过，App 与安装镜像的票据校验通过；源代码及下载见 [Release](https://github.com/PengboQin/tv-volume-keys/releases/tag/v0.2.0-preview.1)。
- 从旧预览保数据更新后，正常打开 App，单外接 HDMI 和 ADB 就绪；新 App 自身加减、静音与取消静音验证成功并恢复原状态。
- 用户移除旧辅助功能条目、重新添加当前 App 后，实际键盘能够控制电视。正常进程报告辅助功能、event tap 与 active 均为 true，记录到媒体键和成功 ADB 命令，错误为空。

这是本次连接的验证，不包含所有 M1、电视、转接器、声音输出方式或重启持久性。音量条变化也不等于能直接控制光纤音响本体音量。

## 辅助功能显示已开，键盘却不生效

本次从旧 ad-hoc 预览升级到 Developer ID 发行后，系统设置中的旧条目已开启，但新版实际进程仍未获得辅助功能权限。单独重启 App 没有恢复；重新添加当前 App 后恢复。现有证据与旧权限条目未授权到当前签名相符，没有修改系统权限数据库来证明内部原因。

1. 确认操作的是运行本工具的那台 Mac，App 位于“应用程序”。
2. 在“系统设置 → 隐私与安全性 → 辅助功能”移除旧的本工具条目。
3. 点“＋”，从“应用程序”添加 **TV Volume Keys Preview.app** 并开启。
4. 看菜单状态是否仍提示等待权限；必要时退出并重新打开本 App。
5. 按音量减、加各一次确认；标准 F 键模式同时按 Fn。

只处理本 App 的条目。不要运行全局权限重置、编辑 TCC 数据库、关闭 Gatekeeper 或重复重新签名来绕过问题。若权限已就绪仍无效，分别检查 HDMI 输出、选中的 CEC/ADB 通道和菜单错误；不要把权限、网络连通与按键成功混作同一状态。

发布附件 `release-validation.json` 保留发布当时“物理键盘待验收”的事实，本页记录发布后的验收补充；未替换既有安装包或校验和。家庭地址、设备身份、配置及原始运行记录不公开。
