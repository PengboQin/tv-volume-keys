# 电视音量键 · TV Volume Keys

让 Mac 键盘的音量加、减、静音键控制兼容的 HDMI 电视。免费、MIT 开源，无账号、广告、遥测或音频驱动。

**当前为实验预览版：安装包使用 ad-hoc 签名，尚未公证。**

## 能适配什么

- Apple 芯片 Mac、兼容的 HDMI-CEC 连接、单个外接屏幕；Mac 默认声音输出走 HDMI。
- 不限定电视品牌，由程序检测当前连接。编译最低系统为 macOS 14。
- 当前只有 M4 Mac mini + macOS 27.0.1 + 雷鸟65S585C Pro 的实机依据。其他 Mac、电视、macOS 版本、转接器、接收器和扩展坞均需验证；不能宣称“所有 Mac mini 都支持”。
- 对使用同一电视声音输出的普通程序，无需逐个开发插件。App 自选声音设备、独占音频和外接音响链路仍可能影响实际响度。

它调节电视的音量设置，不取代 macOS 的 HDMI 音量滑块，也不能经光纤直接控制外接音响本体。当前实现使用非公开 IOKit CEC 接口，系统升级后可能需适配。

## 本地构建

需要现有 Xcode 命令行工具和 Python 3，无第三方依赖下载：

```sh
python3 scripts/build.py --dry-run
python3 scripts/build.py --package
```

`.build/` 保存当前候选，`dist/` 保存预览 DMG、源码 ZIP、校验和与验证摘要。验证摘要包含本机连接状态，不作为公开附件上传。脚本显式编译 arm64 / macOS14，不会安装、启动、覆盖现有应用或公开上传。

## 正常使用

1. 将 App 放入“应用程序”并打开，从菜单栏 `TV` 入口检查连接。
2. 电视开启 CEC，Mac 声音输出选择该 HDMI 屏幕。
3. 在菜单中选“允许键盘控制”，由用户在系统辅助功能中授权。
4. 使用音量键；顶行设为标准 F 键时同时按 Fn。

菜单可手动调音量、暂停接管、退出，或用 macOS 原生登录项功能设置登录启动（默认关闭）。Option/Command/Control 与音量键的组合保留给系统。长按不会堆积松手后的音量操作，静音长按不连续切换。

本预览版检测到早期家庭工具正在运行时会拒绝接管，避免双重调节。不为测试预览版替换用户已经验收的日用候选。
